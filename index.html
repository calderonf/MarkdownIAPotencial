01 · 10 minutos

La IA lee señales, no intenciones ocultas.

Una instrucción vaga obliga al modelo a completar vacíos. Una instrucción estructurada reduce ambigüedad, permite revisar el resultado y facilita reutilizar la solicitud.

Piensa en el marcado como señalización. Títulos separan temas; listas separan acciones; tablas hacen comparables los datos; etiquetas identifican campos.

Solicitud vaga

“Resume este documento y dime qué hacer.”

Solicitud con CREA

# C · Contexto y rol
Actúa como analista de procesos. Usa solo el texto entre <documento>.

<documento>
[pegar contenido]
</documento>

# R · Restricciones y criterios
No inventes datos. Máximo 120 palabras.

# E · Estructura de salida
- Resumen ejecutivo
- Tabla: hallazgo | riesgo | acción propuesta
- Preguntas pendientes

# A · Acción
Analiza el documento y prioriza las acciones.

04 · 12 minutos

CREA: una plantilla breve para prompts útiles.

Delimitar no es complicar el prompt. CREA ayuda a que la IA sepa cuál es el entorno, las reglas, el entregable y el trabajo que debe realizar.

C

Contexto y rol

Situación, antecedentes, fuentes disponibles y perspectiva de trabajo.

R

Restricciones

Límites, criterios, tono, extensión y lo que no debe inventar.

E

Estructura de salida

El formato verificable: tabla, lista, JSON, XML, Markdown o código.

A

Acción principal

La orden concreta: analiza, redacta, extrae, compara o resume.

Prompt CREA para copiar y adaptar

## C · Contexto y rol
Actúa como analista de procesos. Usa solo el procedimiento incluido abajo.

<procedimiento>
[pegar aquí un documento público o previamente autorizado]
</procedimiento>

## R · Restricciones y criterios
- No inventes datos ni normas.
- Si falta información, inclúyela en “Preguntas pendientes”.
- No incluyas datos personales.

## E · Estructura de salida (Markdown)
1. Resumen ejecutivo
2. Pasos del proceso
3. Riesgos o cuellos de botella
4. Recomendaciones priorizadas

## A · Acción
Analiza el procedimiento y prioriza las mejoras propuestas.

05 · 12 minutos

Graphviz: pedir un diagrama en vez de dibujarlo a mano.

DOT es un lenguaje de texto para describir nodos y conexiones. La IA puede proponerlo; tú validas el proceso y el diagrama.

DOT
digraph Compra {
  rankdir=LR;
  node [shape=box, style=rounded];

  Necesidad -> Solicitud;
  Solicitud -> Revision;
  Revision -> Aprobacion;
  Aprobacion -> Cotizaciones;
  Cotizaciones -> Seleccion;
  Seleccion -> Orden_de_compra;
  Revision -> Ajustes [label="incompleta"];
  Ajustes -> Solicitud;
}

06 · 12 minutos

JSON y XML: cuando la salida no es un informe sino datos.

Pídelos cuando necesitas campos consistentes, comparables o reutilizables en una hoja de cálculo, formulario o sistema.

JSON: campos y valores

Práctico para pedir a una IA que entregue información homogénea. Las llaves y comillas importan: un JSON válido permite que otra herramienta lo procese.

Descargar ejemplo JSON ↓
{
  "solicitud": {
    "area": "Recursos Físicos",
    "tipo": "compra",
    "prioridad": "media",
    "items": [{ "nombre": "Silla ergonómica", "cantidad": 20 }],
    "fecha_limite": "2026-09-30"
  }
}

XML: información con etiquetas

Útil cuando importa la jerarquía y la descripción explícita de cada parte de un documento o intercambio.

Descargar ejemplo XML ↓
<solicitud>
  <area>Recursos Físicos</area>
  <tipo>compra</tipo>
  <prioridad>media</prioridad>
  <items><item cantidad="20">Silla ergonómica</item></items>
  <fechaLimite>2026-09-30</fechaLimite>
</solicitud>
Antes de pedir JSON/XML

Define los campos, sus valores permitidos y qué debe hacer la IA cuando no conoce un dato: ¿dejarlo vacío, usar null o preguntarte?

07 · 8 minutos

De PDF a Markdown: menos ruido, más contexto útil.

Un PDF está diseñado para verse bien; Markdown conserva una versión de texto y estructura más fácil de revisar, recortar y entregar a una IA.

1

Elige

Un documento público o una copia autorizada y sin datos sensibles.

→
2

Convierte

Obtén texto estructurado: títulos, listas, tablas y enlaces.

→
3

Revisa

Corrige errores de lectura, tablas y encabezados.

→
4

Recorta

Comparte con la IA solo el fragmento necesario.

Privacidad primero. No subas a servicios públicos documentos internos, financieros, personales o confidenciales. Para el taller usa material público o un ejemplo preparado.

MDFlux: la alternativa práctica para Windows

MDFlux ↗ es una aplicación local, sin terminal, para convertir PDF, documentos Office y escaneos en Markdown preparado para IA. Al conservar títulos, listas y tablas —y evitar enviar páginas como imágenes— ayuda a reducir el contexto y los tokens que la IA debe procesar. Incluye OCR y conversión de carpetas completas.

Funciona en Windows; revisa siempre el Markdown resultante antes de usarlo. MarkItDown sigue siendo la biblioteca de referencia que inspira este flujo.

08 · 5 minutos

El texto tiene partes que no se ven.

Espacios, tabulaciones, saltos de línea y algunos caracteres Unicode determinan cómo se interpreta un texto.

␠

Espacio

Separa palabras; varios espacios pueden colapsarse al mostrar texto.

↵

Salto de línea

En Markdown puede iniciar un párrafo, una lista o un bloque.

⇥

Tabulación

Puede alterar una indentación o la lectura de un bloque.

U+200B

Ancho cero

No se ve, pero puede afectar búsquedas, enlaces y copias.

Hábito saludable: si una copia se comporta de forma extraña, no asumas que es “magia de IA”. Pega una versión corta en un visor de caracteres y revisa qué contiene. Abrir visor ↗
